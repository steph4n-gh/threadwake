# Public alpha release checks

This release is an experimental public alpha, not a whole-game completion claim.

## What was exercised

- The authored browser edition was operated under a project URL subpath: title readiness, Begin/welcome, movement, authored briefing, service-plate discovery, one manual horn setting, Pause, normal reload and saved Continue. The setting and discovery persisted. No model request was issued by that browser check.
- The public Node/Python CPU suite covers campaign/saves/authored fallback, optical rules, record matching, bounded proposal validation, invalid-worker recovery, loopback host deadlines/origins/reuse, pinned model setup, guard failure handling and probe child cleanup. These use labeled authored scenarios and toy workers; they are not native-model or human playthrough evidence.
- A tiny synthetic Gemma model exercised the owned MLX adapter's tied/untied and quantized projections, nonzero focused/broad edits, restoration on errors and unchanged model weights. That is a mathematical adapter check, not a run of a full public checkpoint.
- Both pinned model repositories were downloaded explicitly and all manifest sizes/SHA-256 values verified: 8,762,327,033 bytes in an external development cache. No model weights or raw diagnostic logs are distributed with the repository or browser edition.
- Two separately retained bounded native attempts yielded at the first capture. The first used a generic busy message; after improving diagnostic precision, the second reported other MLX Python activity. Neither completed a capture, work order or record match. Guards remained enabled, owned workers were cleaned up, and no other process was stopped. Full native inference is therefore experimental and unqualified.
- The 15-page public PDF preserves all 190 player-content blocks and 11 FAQ answers. Two independent reviewers inspected all pages. A portable-font map-label overflow was corrected. Cover/portrait placements preserve natural aspect ratios, without cropping or upsampling; diagrams are vector. The reproducible builder and font notices are included.

## Remaining gates

A complete final-build campaign playthrough by an unfamiliar player, a meaningful human hour of play, sustained performance across hardware, physical printing, broad accessibility and full pinned-checkpoint native execution remain open. The opening/manual browser check is a bounded integration test. It does not establish all of those outcomes.

The public GitHub checks and release assets identify the published commit and artifact hashes. Report new results with the exact release/revision, platform, mode and assistance used. Preserve errors, unchanged steering results and yielded attempts as well as successes. Do not turn a file-presence check, authored calibration or archived replay into a claim of fresh inference.
