# Security

The current public alpha is supported on a best-effort basis. The host is designed for your own loopback connection, not exposure as a public or multi-user service. Optional models run locally; model downloads require explicit consent.

Report security issues privately through the repository’s GitHub Security tab if private vulnerability reporting is available. If it is unavailable, open an issue titled “Private security contact requested” without sensitive details so the contributors can arrange a private channel. There is no published security email address or guaranteed response deadline.

Include the affected revision, platform, reproduction steps and scope of impact. Share only the minimum necessary data; prompts, saves and diagnostic logs may contain private text. Do not post secrets, model weights, raw personal logs or exploit details in a public bug report.

For ordinary gameplay defects, use the bug-report template. Review [docs/LOCAL_MODEL.md](docs/LOCAL_MODEL.md) for model terms, local data and diagnostics behavior.
