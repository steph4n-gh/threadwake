# Contributing

Threadwake is a public alpha. Useful contributions make a repair, choice or signal easier to understand and more satisfying to play.

For a small fix, explain the concrete before/after behavior in a pull request. For a larger feature, open an issue describing the player problem and the smallest experiment that could answer it. Preserve existing work and keep unrelated changes separate.

Run the checks in [docs/TESTING.md](docs/TESTING.md). For visual changes, include actual unmodified screenshots and the viewport; for guide/PDF changes, inspect all affected layouts and every PDF page. Report remaining limits plainly rather than treating compilation or a fixture as a full playthrough.

Keep the distinction between authored references, historical replays and actual local measurements. Preserve explicit agreement acceptance, work-order review, save-origin behavior and the no-model play path. New assets need provenance and rights compatible with the applicable licenses. Do not commit model weights, local caches, raw player logs, secrets or personal paths.
