# Changelog

## 0.1.0-alpha.1 - 2026-10-31

Initial public alpha.

- Play the 3D authored demo without downloading a model.
- Repair observatory machinery, review work orders, make explicit crew agreements and route complete signal spectra through optical instruments.
- Optionally install pinned Gemma checkpoints for experimental local MLX capture, interpretation and record matching on Apple Silicon.
- Read the illustrated field guide in the browser or as a downloadable PDF.
- Run the offline public CPU and package checks.

This is not a declaration of full-game completion, an hour of qualified gameplay, universal fresh-machine support or sustained-performance qualification. Public local-model behavior and hardware coverage remain experimental.
